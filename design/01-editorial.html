Straight-bar Dips

  1. Support yourself on top of a single straight bar, hands just outside your hips, arms locked.
  2. Lean slightly forward and bend the elbows until the bar reaches your lower chest / upper abs.
  3. Press back to a full lockout at the top.

Cue: the other half of the muscle-up — the top-out is exactly this position.

Trade-offs

Wins

Instant personality and a real sense of occasion — the day's session reads like a cover line, and the numbers become the visual. Scanning "what am I doing today" takes one glance because there is exactly one thing at that size.

Costs

Display type at 84px eats vertical space, so a 390px pane needs more scrolling per view; long exercise names ("Pistol Squat Progression") wrap awkwardly at that size and need a tuned clamp. It also depends on a condensed webfont — offline, iOS falls back to a system stack and loses roughly half the character.

Mapping onto src/styles.css

  • Replace .gv-hero's gradient block entirely: drop background: linear-gradient(...) and box-shadow, keep the element as a plain full-bleed section. Lime survives as the highlighter sweep behind the second display line.
  • Add one token — --gv-display — and route .gv-hero-title, .gv-tile-big, .gv-ex-name, .gv-goal-nums b at it. Everything else keeps the existing system stack.
  • Set --gv-radius: 0 and --gv-shadow: none; .gv-card becomes a hairline-bottom row using the existing --gv-line. All state colours (--gv-lime, --gv-lime-deep, --gv-lime-ghost) carry over untouched, so the dark-theme block still works.
